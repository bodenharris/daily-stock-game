# Morning report

CI and deploy workflows now live in `.github/workflows` (see the README's Deployment section). Deploy and preview stay off until the repository variables `DEPLOY_ENABLED` and `PREVIEW_ENABLED` are set, so nothing has been deployed, and the server, DNS and paid services were not touched.

## Run it

```sh
npm i
npm run dev
```

Open http://localhost:5173 in a phone-sized window. This machine's `.env` already has everything, and the shared database is migrated and loaded.

Setting up a new machine:

```sh
cp .env.example .env            # fill in values
npm run db:migrate              # migrations only add things
node scripts/fetch-prices.ts    # Tiingo → .cache/tiingo (slow: free-plan rate limit)
node scripts/ingest-prices.ts   # cache → prices hypertable, then compress
node scripts/export-catalog.ts  # shared DB → private/catalog.json (git-ignored)
node scripts/seed-puzzles.ts    # private/catalog.json → puzzles table
```

- Checks: `npm run verify` (svelte-check, Prettier, ESLint, Vitest).
- Production build: `npm run build && node build`. Set `PLAY_SOURCE=dev` when running a local build against the shared database, so your test plays stay out of the real crowd.
- Money simulator: `node scripts/simulate.ts`.

## What works

- **The game, playable without an account.**
  - A hidden real chart and five calls with 10/25/50% stakes.
  - Each stretch draws in first. Then the balance, score dot, size of the move, crowd split and payout land.
  - Then "Name the moment": pick which of four shape-matched famous moments this was, or skip. It's only for bragging rights (a 🎯 in the share text), and nothing identifying is sent until the guess is stored.
  - Then the unmasking: headline, ticker, dates, real prices on the chart and a short story, plus an archetype and a one-row share grid that spoils nothing.
- **Honest server.**
  - The browser never gets future bars, dates or the ticker before the reveal.
  - Every call settles in a transaction with a row lock.
  - The daily schedule is stored and secretly shuffled, so the repo doesn't reveal the order and a day's puzzle can't change mid-game.
  - Three hours of grace after midnight for a game in progress.
  - The reveal is only sent after the Name it guess is stored.
- **Crowd payout:**
  - A wrong call loses the stake; a right call wins the stake back plus a crowd bonus (up to 10% of your balance) when most players called it the other way. A right call never pays less than the stake.
  - Blended with a 10-player 50/50 prior on quiet mornings, locked at the moment you call, and explained in dollars in the result line ("Right. 1 of 4 players called up. Crowd bonus +$6.").
- **Accounts and streaks:**
  - The first call creates an anonymous player.
  - Email and password sign-up keeps today's game and every past one.
  - The streak shows in the header and the account sheet.
- **Live stats** (`/stats`):
  - One shared query every 3 seconds, streamed with `query.live`.
  - Your finish and percentile, and the crowd's split per call, but only after you've finished.
  - The Tiger Data details are in a collapsed "How this page works".
- **Past charts** (`/archive`): the game launched on Nov 1, so today is #14 and there are 13 past days. Every day so far is listed, with your result on each, playable any time at `/day/N`. Past days are scored against that day's players ("3rd of 16 players") and don't count toward your streak.
- **Tiger Data**, all visible and fast. Database time is under 0.2 ms for every stats query; round trips from this laptop are about 23 ms.
  - Hypertables: `prices` and `guesses`, both with columnstore compression.
  - Continuous aggregates:
    - `crowd_hourly`: real-time, feeds the payout.
    - `crowd_daily`: hierarchical, rolled up from `crowd_hourly`.
    - `finals_hourly`: a Toolkit `percentile_agg` for the median finish (and a fallback estimate of your rank).
  - `time_bucket_gapfill` for the 24-hour chart.
  - Users, sessions, puzzles, schedule and games are ordinary tables in the same database.
- **Data:** 96 hand-picked puzzles from 1982 to 2025, each window checked against real prices and each story fact-checked against news coverage; daily bars for 122 tickers, compressed in the columnstore.
- **Private catalog:** the answers live in the shared database and a git-ignored `private/catalog.json`, not in the public repo (`scripts/catalog.example.json` shows the format). The schedule picks the next unplayed puzzle with a secret-keyed hash, so the catalog can grow or shrink at any time without repeats.
- **Reveal extras:** prices as quoted at the time (later splits undone, so GameStop peaks at $348), and "In hindsight: a year later it was …" read live with TimescaleDB's `last()`.
- **Sharing:** a one-row share grid with your place today ("🎓 Paid Tuition · 3rd of 6 today"), an Open Graph preview card (`static/og.png`) and app icons, all generated by `scripts/make-images.py`.
- **Leaderboard:** the reveal ends with the day's top 10 finishes and your own place, with no names, only each player's archetype. The stats page opens the same board from a Leaderboard button once you've finished. Your place there, in the share text and on the stats page is the same exact rank.
- **Look:** Material 3 Expressive in green, light and dark following the system, self-hosted Google Sans Flex and Roboto Flex. Checked at 375×812 and 320×568.
- **Desktop:** from 1024px, a big chart on the left and a game rail on the right with a call log; keyboard play (↑/↓ to call, 1/2/3 to bet); sheets become dialogs from 768px; the stats page goes two-column.
- **Tests:** 125 covering money math, payout, daily selection (midnight Eastern, DST), the schedule (no repeats as the catalog grows or shrinks), Name it options, streaks (archive plays don't count), archetypes, share text, split adjustment and puzzle outcomes.

## Known issues and limits

- **Recognisable charts:** the first 30 puzzles were in the public repo before the catalog went private, so they are still in git history. The 66 added since never were. A determined player could still recognise a famous chart. The leaderboard has no names or prizes, so that's still accepted.
- **Proxy setting for production:** behind Caddy, set `ADDRESS_HEADER=X-Forwarded-For` and `XFF_DEPTH=1`, or the per-IP limit on new anonymous players stays off.
- **Replays:** a player can replay a day by clearing cookies, and can move a perfect anonymous game onto an account by signing in. The leaderboard has no names or prizes, so I accepted it (see decisions).
- **Accounts:** there's no email verification and no password reset, because there's no email service.
- **Licence:** Tiingo's free plan doesn't allow public display (a risk product.md already lists).

## Decisions

All in `docs/decisions.md`. The big ones:

- **A right call never pays less than the stake.** The crowd bonus is the same dollars on every chip, which keeps always-max-stake from beating careful sizing: thoughtful play wins 30 of 30 simulated scenarios on median, log return and days won.
- **Green and coral mean right and wrong.** Never up and down.
- **Each call gets an equal slice of the chart.** The chart uses a log scale and straight segments.
- **Today's crowd split is hidden until you finish,** so nobody can use it to game the payout.
- **Dev plays are tagged `dev`** and never count toward the real crowd or the public stats.
